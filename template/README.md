## 🛠 Реализованные технические решения

### Обязательные требования (для всех уровней)
* **Семантика без JS:** использованы `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, строго один `<h1>`, ни одной строки JavaScript.
* **CSS Grid и Flexbox:** адаптивная сетка проектов на `repeat(auto-fit, minmax(min(100%, 17rem), 1fr))` и раскладка шапки/карточек на Flexbox.
* **CSS Nesting:** использована нативная вложенность с селектором `&` в блоке *(укажите селектор, например `.project-card`)*.
* **Container Queries (`@container`):**
  * **Контейнер:** элемент *(укажите селектор, например `.project-slot`)* с `container-type: inline-size`.

* **Доступность (A11y):** настроены `:focus-visible`, контрастность текста и `@media (prefers-reduced-motion: reduce)`.
