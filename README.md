## 🎯 Цель и сценарий проекта

Собрать и вывести в реальный продакшен **личный Сайт-Портфолио фронтенд-разработчика** без использования JavaScript и сторонних CSS-фреймворков. Этот сайт станет вашей профессиональной визитной карточкой для резюме, LinkedIn и GitHub, а также площадкой, на которую во втором семестре вы добавите интерактивные проекты на JavaScript.

## 🎨 Обязательный визуальный модуль: Художественный портрет автора

Чтобы портфолио выделялось среди шаблонных страниц, каждый студент должен обработать своё фото (или сгенерировать стилизованный портрет по своему референсу) с помощью ИИ строго в **одной из трёх художественных техник на выбор**:

1. **Сухая пастель (`Soft Pastel`):** бархатистые переходы тона, видимая фактура зернистой художественной бумаги, мягкие штрихи.
2. **Уголь с пастелью на тонированной бумаге (`Charcoal & Pastel on Toned Paper`):** графичный контрастный рисунок углём на крафтовой/серой/бежевой бумаге с деликатными цветовыми акцентами пастелью в тон вашего `--color-accent`.
3. **Цифровая живопись маслом (`Digital Oil Painting`):** выразительные фактурные мазки кисти, глубокий светотеневой объём в духе современного портрета.

### Промпты-шаблоны для генерации портрета (загрузите своё фото как референс)

* **Для техники `Soft Pastel`:**
  > `Portrait of the person from the reference photo, rendered in authentic soft pastel technique on textured fine-tooth art paper. Visible velvety pastel strokes, gentle color blending, warm soft studio lighting, harmonious palette matching [ВАШ ОСНОВНОЙ ЦВЕТ ИЗ ПАЛИТРЫ], clean neutral paper background, high detail, editorial portrait illustration.`
* **Для техники `Charcoal & Pastel on Toned Paper`:**
  > `Expressive fine art portrait of the person from the reference photo, drawn with natural black charcoal and subtle pastel highlights on warm toned grey-beige craft paper. Visible charcoal hatching, dramatic light and shadow contrast, delicate color accents in [ВАШ ОСНОВНОЙ ЦВЕТ ИЗ ПАЛИТРЫ] pastel chalk, authentic hand-drawn sketchbook aesthetic.`
* **Для техники `Digital Oil Painting`:**
  > `Digital oil painting portrait of the person from the reference photo, rich impasto brushstrokes, expressive painterly texture, classic studio chiaroscuro lighting, modern concept-art portrait style, deep atmospheric background with subtle [ВАШ ОСНОВНОЙ ЦВЕТ ИЗ ПАЛИТРЫ] color accents, sharp focus on eyes.`

### Инженерные требования к изображениям
* Минимум **3 локальных оптимизированных изображения** в папке `images/` (портрет автора + минимум 2 превью/схемы проектов).
* Портрет должен быть сжат в формат **`.webp`** (вес до `250 КБ`) и подключён через тег **`<picture>`** с фоллбэком на `.jpg`/`.png` и явными атрибутами `width` и `height` (защита от скачков макета CLS).

## 🛠️ Обязательные технические требования (HTML5 + Modern CSS 2026)

1. **Семантика без «дивитиса» и нулевой JS:**
   * Используйте `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`.
   * Строго один `<h1>` (ваше имя / позиционирование), логичная иерархия `<h2>` $\rightarrow$ `<h3>`.
   * **Запрещены:** JavaScript (`<script>`, `.js`), CSS-фреймворки (Bootstrap, Tailwind) и `!important` как способ починить каскад.
2. **Архитектура современного CSS:**
   * **Дизайн-система (`:root`):** вся палитра (согласованная с цветами вашего портрета), отступы, радиусы и шрифты вынесены в CSS Custom Properties.
   * **CSS Grid:** глобальный каркас страницы и адаптивная сетка проектов (`repeat(auto-fit, minmax(min(100%, ...), 1fr))`).
   * **Flexbox:** навигация в шапке (`margin-left: auto` у кнопки связи) и внутреннее выравнивание элементов внутри карточек.
   * **Нативная вложенность (CSS Nesting):** минимум в одном логическом блоке с корректным `&` (без Sass-конкатенации `&__element`).
   * **Container Queries (`@container`):** минимум один компонент (например, карточка проекта) должен адаптироваться к ширине своего родительского контейнера (`container-type: inline-size`), а не к ширине окна браузера.
3. **Содержательное наполнение портфолио:**
   * **Секция «Обо мне / Позиционирование»:** расскажите, как ваш предыдущий профессиональный опыт (биология, аналитика, менеджмент, логистика, финансы и т. д.) усиливает вас как фронтенд-разработчика.
   * **Секция «Проекты» (минимум 4 карточки):**
     * 3 карточки — ваши реальные работы первого семестра (командный макет Figma «ДВИЖ»/«GYMBY», Dashboard на Flexbox, Коммерческая витрина на Grid) с живыми ссылками на репозитории GitHub.
     * 4-я карточка (выделенная через `:has()` или `span 2`) — **анонс вашего «флагманского» пет-проекта** из вашей предметной области, который вы оживите на JavaScript во втором семестре.
4. **Адаптивность и доступность (A11y):**
   * Корректное отображение от **`320px`** до **`1440px+`** без горизонтального скролла.
   * Полная навигация с клавиатуры (`Tab`, `Enter`) с заметным `:focus-visible`.
   * Поддержка системной настройки `@media (prefers-reduced-motion: reduce)` для отключения необязательных анимаций.

## 🏆 Уровни сложности (Система Анти-ИИ)

Вы выбираете **один** уровень при сдаче работы (каждый следующий включает требования предыдущих):

* Сайт опубликован на **GitHub Pages** и открывается по публичной ссылке.
* Заполнены ответы на 2 вопроса рефлексии в `README.md`.

### 🔵 Уровень JUNIOR (до 90 баллов)
* Всё из **BASE**, плюс:
* **Архитектурное ограничение проекта** (выберите одно и опишите его в `README.md`):
  * *Вариант А:* Вся архитектура стилей организована через каскадные слои `@layer reset, base, components, utilities;` без единого `!important` и правил вне слоёв.
  * *Вариант Б:* Все отступы (`margin`, `padding`, `gap`) подчинены строгой 8-точечной сетке (кратны `8px` / `0.5rem`).
* Чистая история из **4–5 атомарных коммитов** по логическим этапам (`[header]`, `[hero-portrait]`, `[projects-grid]`, `[container-card]`, `[deploy-docs]`).

### 🔴 Уровень PRO (до 100 баллов)
* Всё из **JUNIOR**, плюс:
* **Семантически валидная вложенная структура:** внутри карточек проектов `<article>` использован список определений `<dl>` (`<dt>` / `<dd>`) для метаданных (Роль, Стек, Год), либо в секции навыков — вложенные списки `<ul>` внутри `<li>`.
* **Инженерный стресс-тест на `320px`:**
  * Текст в блоке «Обо мне» объёмом **не менее 100 слов** + неделимое техническое слово длиной **более 40 символов** (например, `ContainerQueriesAndCascadeLayersArchitectureTest`) внутри гибкого контейнера.
  * При ширине `320px` текст и длинное слово корректно переносятся (`overflow-wrap: anywhere`), не ломая сетку и не вызывая горизонтального скролла.
* **Скриншот из DevTools (`320px`)** в `README.md` / PR, подтверждающий работу `@container` (или `@layer`) и отсутствие горизонтальной прокрутки.

## 🚀 Порядок публикации на GitHub Pages и сдачи работы

### Шаг 1. Создание личного репозитория и деплой
1. Создайте в своём аккаунте GitHub **новый публичный репозиторий** (например, `portfolio` или `<ваш-логин>.github.io`).
2. Загрузите в корень этого репозитория файлы вашего сайта (`index.html`, `css/style.css`, `images/`, заполненный по шаблону `README.md`).
3. Перейдите в настройки репозитория: **Settings $\rightarrow$ Pages $\rightarrow$ Build and deployment**:
   * **Source:** `Deploy from a branch`
   * **Branch:** `main` / `/ (root)` $\rightarrow$ нажмите **Save**.
4. Дождитесь сборки (1–2 минуты), скопируйте готовую публичную ссылку вида `https://<ваш-логин>.github.io/portfolio/` и добавьте её в поле **Website** (раздел *About* справа в репозитории).

### Шаг 2. Регистрация работы в учебном репозитории `fufaev/css_lesson_12`
1. Сделайте **fork** репозитория `fufaev/css_lesson_12`, создайте ветку `homework-12`.
2. Создайте папку `Фамилия_Имя_Группа/` и скопируйте туда свой заполненный файл `README.md` (с живой ссылкой на GitHub Pages, ссылкой на исходный код и скриншотом из DevTools).
3. Откройте **Pull Request** из ветки `homework-12` в `fufaev:main`.
